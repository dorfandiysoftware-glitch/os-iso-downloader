# os-iso-downloader

Windows-застосунок (WinUI 3), який качає ISO-образи ОС з офіційних серверів.
Потік: **Завантажити → система → підрозділ → версія/білд → файл**.

- `catalog/catalog.json` — каталог (схема v1). Застосунок бере його з GitHub, а якщо зв'язку немає — вбудований.
- Записи типів: `iso` (качається), `archived` (старе, з попередженням), `guide` (відкриває офіційну сторінку).
- `verified: true` — лише якщо посилання бачили на офіційній сторінці. CI щотижня перевіряє посилання (`tools/check_links.py`).
- `resolve` шукає найновіший файл у списку директорії, тож нові релізи не потребують правки каталогу.
- Завантаження з паузою/продовженням (HTTP Range) та перевіркою SHA-256/512.
